# Artsphere

## Overview

Artsphere is a creative web app built during Boolean’s Coding Nights, inspired by TikTok and designed for artists and creatives. With guidance from Samuele and skills revived from the Apple Foundation Program, this project blends inspiration, interaction, and artistic expression into a smooth, immersive experience.

## Features

- Scroll through a curated feed of artistic videos  
- Like, bookmark, and comment on content  
- Toggle audio for personalized viewing  
- Minimalist design with smooth transitions  
- Responsive layout for mobile-first experience

## How to Run

1. Clone the repository  
2. Open `index.html` in your browser  
3. Explore, interact, and get inspired!

## Tech Stack

- HTML5, CSS3, JavaScript  
- Font Awesome for icons  
- Google Fonts for typography
